# Ultrasonic Range Finder Using 8051

## 📌 Description
This project measures distance using HC-SR04 ultrasonic sensor and 8051 microcontroller.

## ⚙️ Components
- AT89C51
- HC-SR04 Sensor
- Crystal Oscillator(11.0592)
- Resistors10k
- Capacitors(33pf)
- capacitor(10uf)
- LCD Display
- pot(10kohm)
- push button 

## 🧠 Working
Trigger pulse → Echo received → Time calculated → Distance measured

## 📏 Formula
Distance = (Time × Speed of Sound) / 2

## 💡 Applications
- Parking Sensor
- Obstacle Detection
- Distance Measurement
